PromptWall Frequently Asked Questions

What is PromptWall?

PromptWall is a GPLv3 fork of TinyWall. It keeps TinyWall's direct Windows Filtering Platform, default-deny design and adds a bottom-right prompt for newly blocked outgoing TCP or UDP connections.

What do Allow outgoing and Ignore do?

Allow outgoing creates a permanent outbound TCP/UDP exception for the service-owned identity in the prompt. It does not open inbound listener ports. Ignore keeps the connection blocked and suppresses another prompt for that identity for five minutes.

Why is Allow sometimes disabled?

Shared service hosts can run several Windows services in one process. If PromptWall cannot prove one exact service identity, it keeps blocking and disables Allow instead of creating a broad executable exception.

Which blocks create prompts?

Only outbound TCP/UDP drops caused by PromptWall's normal-mode default block. Explicit user blocks, blocklists, inbound drops, raw-socket protections, Block All mode, and other firewall modes never create an allow prompt.

Can I install remotely?

No. Installation activates default-deny filtering and can immediately disconnect remote administration. Use an expendable Windows VM with a snapshot and a working local or virtual console. Do not install TinyWall and PromptWall together.

Does PromptWall check for updates?

No. The inherited TinyWall update feed is disabled because it cannot safely update this fork. Install reviewed PromptWall builds manually.

Where are settings and logs?

Machine data is stored under C:\ProgramData\PromptWall. PromptWall also uses a LocalSystem Windows service and a separate tray controller.

How do I recover from a bad rule or lockout?

Use the local console to switch mode, remove the exception, or uninstall PromptWall through Windows Apps and Features. Never delete the installation directory by hand.

What is the license and upstream?

PromptWall is licensed under GNU GPL version 3 or later. It is based on TinyWall by Károly Pados. Source provenance is included with the distribution.
